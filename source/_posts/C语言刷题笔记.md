## 一、C 程序的基本骨架

```c
#include <stdio.h>

int main()
{
    // 你的代码

    return 0;
}
```

**要点**

- `#include <stdio.h>` 用 `scanf` / `printf` 必须有
- `main` 是程序入口
- `return 0;` 表示程序正常结束（不写也能过，但养成习惯）

## 二、输入输出 scanf / printf

### 核心规则

> **`scanf` 要地址（`&`），`printf` 要值（不用 `&`）。**

```c
int x;
scanf("%d", &x);      // ✅ 要 &
printf("%d", x);      // ✅ 不要 &
```

**为什么？**

- `scanf` 要**往变量里写数据**，必须知道变量在哪 → 给**地址**（`&x`）
- `printf` 只是**读变量的值** → 给**值**（`x`）

**漏掉 `&` 的后果：程序崩溃 → RE**（踩过三次）

### 数组是例外

```c
char s[100];
scanf("%s", s);       // ⚠️ 数组名本身就是地址，不要加 &
```

### 多组数据的读法

```c
// 固定 7 组：循环 7 次
for (int i = 1; i <= 7; i++)
{
    int a, b;
    scanf("%d%d", &a, &b);
    // ...
}

// 题目第一行给个数：先读个数，再循环
int n;
scanf("%d", &n);
for (int i = 0; i < n; i++) { /* ... */ }
```

**⚠️ 数清楚题目给了几组数据** —— 多读一次会吃掉后面的数据，全盘错位。

## 三、数据类型与格式符对照表

### ⭐ 必背表

| 类型 | `scanf` | `printf` |
|---|---|---|
| `int` | `%d` | `%d` |
| `long long` | `%lld` | `%lld` |
| `float` | `%f` | `%f` |
| **`double`** | **`%lf`** | **`%f`** |
| `char` | `%c` | `%c` |
| 字符串 | `%s` | `%s` |

### ⚠️ 最容易错的点

> **`double` 在 `scanf` 里用 `%lf`，在 `printf` 里用 `%f`！**

**原因**：`printf` 会把 `float` 自动提升为 `double`，所以不用区分；`scanf` 拿到的是指针，必须区分。

### 输出控制格式

| 写法 | 效果 | 例子（值 3.14159） |
|---|---|---|
| `%d` | 整数 | — |
| `%f` | 默认 6 位**小数** | `3.141590` |
| `%.3f` | 3 位小数 | `3.142` |
| `%.1f` | 1 位小数 | `3.1` |
| `%g` | 6 位**有效数字** | `3.14159` |
| `%.6g` | 6 位有效数字 | `3.14159` |
| `%02d` | 宽度 2，不足补 0 | `08` |
| `%*c` | 宽度用变量控制 | — |

### ⚠️ 小数位数 vs 有效数字

```
%f  → 数的是"小数点后几位"    166.666667
%g  → 数的是"从第一个非零数字起一共几位"   166.667
```

**题目说"保留 6 位有效数字" → 用 `%g`；说"保留 6 位小数" → 用 `%.6f`。**

### ⚠️ `cout` 和 `printf` 的默认精度不同

题目里说"用 `cout` 输出"时，**`cout` 输出 `double` 默认是 6 位有效数字**（相当于 `%g`），**不是 `printf("%f")` 的 6 位小数**。

### ⚠️ `%.1f` 和 `%.lf`

**`1` 是数字一，`l` 是小写字母 L** —— 长得太像，极易看错。

### ⚠️ 尾行换行

**题目输出最后一行通常不加 `\n`**，多一个都可能 WA。（B2005 就栽在这）

**但题目明说"用换行符隔开"时，就要加。**

## 四、变量与命名规范

### 命名原则

```c
int total_jiao = a * 10 + b;   // ✅ 有意义
int x;                          // ⚠️ 太短
int ttl_Jiao;                   // ⚠️ 风格混搭
int min_cost;                   // ✅ 下划线分隔
```

**C 风格**：全小写 + 下划线（`total_jiao`）或驼峰（`totalJiao`），**选一种别混**。

### ⚠️ 不要用这些名字

`cout`、`cin`、`endl`、`string`、`max`、`min`、`count`、`time`、`index`、`y1`

（都是 C++ 或标准库的名字，以后会冲突）

### 变量作用域

```c
if (t == 1)
{
    int apple = 10;    // 只在这个 {} 里活着
}
else if (t == 2)
{
    int apple = 20;    // 另一个 apple，不冲突
}
```

**`{}` 形成作用域，出了 `{}` 变量就消失了。**

## 五、运算陷阱

### ⭐ 陷阱 1：整数除法（踩过 5 次以上！）

```c
500 / 3        // = 166   整数除法，小数全丢
500.0 / 3      // = 166.6667  ✅

4 / 3          // = 1     ❌ 灾难
4.0 / 3.0      // = 1.333 ✅
```

**规则**：**只要算式里有小数，参与运算的数就必须至少有一个是浮点类型。**

**三种修法**

```c
double a = (double)t / n;     // 强制类型转换
double a = t * 1.0 / n;       // 乘 1.0
double a = 4.0 / 3.0 * pi;    // 直接写浮点
```

### ⭐ 陷阱 2：运算符优先级与结合性

```c
m / h * h          // ❌ = (m/h)*h = m，h 被约掉了
m / (h * h)        // ✅ 括号！
```

**`*` `/` `%` 同级，从左往右算；想改变顺序只能加括号。**

### ⭐ 陷阱 3：向上取整 / 向下取整

| 场景 | 方向 | 写法 |
|---|---|---|
| 至少需要几个（不够也进位） | **向上** | `(a + b - 1) / b` |
| 最多能买几个（不够就舍） | **向下** | `a / b` |

**例 1**：走路 10 米，速度 3 米/分 → `(10 + 3 - 1) / 3 = 4` 分钟

**例 2**：需要 57 支铅笔，每包 30 支 → `(57 + 29) / 30 = 2` 包

**原理**：`+ b - 1` 是先垫高一点，让除不尽的情况也能进位，除得尽时又不会多加。

### ⭐ 陷阱 4：浮点数不要用 `==` 比较

```c
if (a == 0.1 + 0.2)     // ❌ 浮点几乎不可能精确相等
if (a > 0.2999)         // ✅ 用 > 或 <
```

**能转成整数比较就转** —— 比如三角形判定用 `a*a + b*b == c*c`，全程整数，绝对精确。

### ⭐ 陷阱 5：`==` 和 `=` 写错（踩过两次）

```c
if (t == 4)     // ✅ 比较
if (t = 4)      // ❌ 赋值！条件永真，t 被覆盖
```

**编译器可能只给警告，不报错。** 防御写法：`if (4 == t)`（写错会立刻报错）

**⚠️ 更隐蔽的版本**：

```c
int packs = (n = per - 1) / per;    // ❌ 想写 +，打成 =
```

**这个 `=` 会把 `n` 的值改掉** —— **循环第二轮开始 `n` 就不是原值了。**

### ⭐ 陷阱 6：整数溢出

| 类型 | 范围 |
|---|---|
| `int` | **±21 亿**（-2147483648 ~ 2147483647）|
| `long long` | **±9.2 × 10¹⁸** |

```c
int min_cost = 100000000;          // ✅ 1 亿，安全
int min_cost = 114514191810;       // ❌ 12 位，溢出，变成垃圾数
long long min_cost = 114514191810; // ✅ 换 long long + %lld
```

**⭐ 判断方法：数位数。10 位以内 `int` 安全，11 位以上要 `long long`。**

**⚠️ 溢出后果**：不报错、不崩溃，就是结果莫名其妙（常常变成负数）。

**⭐ 擂台初始值要"够大"，但不是"越大越好"** —— 要按题目范围估算上界。

### ⭐ 陷阱 7：数据范围

| 范围提示 | 用什么 |
|---|---|
| 保证答案在 int 范围内 | `int` |
| 答案可能到 10^18 | `long long` |
| 没说 | 自己估算会不会溢出 |

**`int` 上限约 21 亿（2.1 × 10⁹）**

### 陷阱 8：类型不匹配导致输出乱码

```c
printf("%d", a * 0.2 + b * 0.3);   // ❌ 算出来是 double，用 %d 打印 = 乱码
```

**`printf` 完全信任格式符**，类型错了它不知道，会读出垃圾。

**⭐ 写 `printf` 前先问自己："这个表达式是什么类型？"**

## 六、逻辑运算符

| 运算符 | 读作 | 含义 |
|---|---|---|
| `&&` | 与 AND | 两边都真才真 |
| `\|\|` | 或 OR | 有一个真就真 |
| `!` | 非 NOT | 取反 |

### ⚠️ 别写成单个 `&` 或 `|`

**单个是位运算**，不是逻辑运算，**写错了不报错但结果全错**。

### ⚠️ C 里没有"是其中之一"的语法

```c
if (month = 1, 3, 5, 7)       // ❌ 完全不是这个意思！
```

**拆开看**：

- `month = 1` 是**赋值**，表达式的值是 `1`
- `1, 3, 5, 7` 是**逗号运算符**，整个表达式的值是**最后一个** `7`
- `7` 非零 → **条件永远为真**

**正确写法**：

```c
if (month == 1 || month == 3 || month == 5 || month == 7)
```

**⭐ 每个都要完整写 `变量 == 值`，不能省略左边。**

### 短路求值

```c
if (i < n && a[i] > 0)    // 左边假 → 右边不看 → 防越界
```

### 关系表达式本身是 1 或 0

```c
int p1 = (x % 2 == 0);       // p1 是 1 或 0
int p2 = (x > 4 && x <= 12);
int both = p1 && p2;         // 可以直接当数用
```

### "刚好一个成立" = 异或

```c
int b = (p1 != p2);    // ✅ 一真一假
```

### 优先级

```
!  >  比较  >  &&  >  ||
```

**不确定就加括号。**

### ⚠️ 判断必须整体包在外层括号里

```c
if(n % 4 == 0 && n % 100 != 0) || n % 400 == 0)    // ❌ 括号位置错
if((n % 4 == 0 && n % 100 != 0) || n % 400 == 0)   // ✅
```

**`if` 后面那对括号是"条件的外壳"，必须包住整个条件。**

## 七、分支进阶：三元运算符与 switch

### 三元运算符 `?:`

**`if-else` 的简写形式**：

```c
条件 ? 成立时的值 : 不成立时的值
```

**例**：

```c
printf("%d", s == 0 ? m : 0);       // s==0 就输出 m，否则输出 0
int max = a > b ? a : b;            // 取较大值
```

### `switch`

**适合"一个变量对多个固定值"的判断**：

```c
switch (month)
{
    case 1:
    case 3:
    case 5:
        printf("31");
        break;              // ⚠️ 别忘了 break
    case 2:
        printf("28");
        break;
    default:                // 相当于 else
        printf("30");
}
```

**⭐ `case` 可以连写**（多个值走同一段代码），**比一堆 `||` 干净**。

### ⚠️ 什么时候用 `if-else`，什么时候用独立 `if`

**这是踩过坑的地方：**

| 情况 | 用什么 | 例子 |
|---|---|---|
| **同一维度的几种情况，互斥** | `if - else if - else` | 锐角/直角/钝角 |
| **不同维度的判定，可叠加** | **独立的多个 `if`** | 等腰 + 等边 |
| **多值匹配** | `switch` | 月份天数 |

**⚠️ 反例**：三角形分类里，等边三角形同时满足"锐角 + 等腰 + 等边"，**要输出 3 行** —— **如果写成 `else if` 只会输出第一行。**

**⭐ 写 `if-else` 链之前先问：这几个分支是在分同一件事吗？**

### `else` 的归属

**`else` 只跟"最近的、还没配对的 `if`"** —— 缩进骗人，看括号。

### 提前退出

```c
if (a + b <= c)
{
    printf("Not triangle");
    return 0;              // ⭐ 不是三角形就没必要往下判了
}
```

**`return 0;` 写在 `main` 里 = 立刻结束整个程序。** 比嵌一堆 `if` 干净。

### 阶梯计价（分段累加）

**现实里的电价、水费、个税都是这种算法** —— **不是整段按一个价，而是每档各算各的。**

```
if (n <= 150)
    第一档：n × 单价1
else if (n <= 400)
    第一档算满 + 第二档：(n - 150) × 单价2
else
    第一档算满 + 第二档算满 + 第三档：(n - 400) × 单价3
```

**⚠️ 最容易错的两点**：

- **后面的分支忘了把前面的档"算满"**
- **把"档位宽度"和"n - 上限"搞混**（第二档宽度是 `400 - 150 = 250`，不是 `n - 150`）

**⭐ 套路**：每一档都要"前档算满 + 本档算超出部分"。

## 八、函数（P1888 首次使用）

### 定义与调用是两回事

```c
int gcd(int a, int b)      // 定义：写在 main 外面
{
    while (b != 0)
    {
        int t = a % b;
        a = b;
        b = t;
    }

    return a;              // ⚠️ 返回的是 a，不是 0
}

int main()
{
    int g = gcd(a, c);     // 调用：传参数进去，拿返回值出来
}
```

**⭐ 类比**：**定义 = 造机器，调用 = 按按钮用机器。**

### ⚠️ 函数不能定义在函数里面

```c
int main()
{
    int gcd(int a, int b) { }      // ❌ C 不允许嵌套定义
}
```

**函数是"平级"的** —— **`gcd` 要写在 `main` 的上方。**

### 参数是"值传递"（复制）

**函数里的 `a`、`b` 是新的变量，值是外面传进来的副本。**

**⚠️ 在函数里改 `a`、`b`，不影响 `main` 里的变量。**

**这就是为什么排序那段必须写在 `main` 里** —— **它要真正修改 `main` 的变量。**

### 辗转相除法求最大公约数（GCD）

```c
int gcd(int a, int b)
{
    while (b != 0)
    {
        int t = a % b;
        a = b;
        b = t;
    }

    return a;
}
```

**原理**：反复用"除数变被除数，余数变除数"，直到余数为 0，**此时的被除数就是 GCD。**

**例**：`gcd(12, 8)` → `(8, 4)` → `(4, 0)` → **返回 4** ✔️

### 分数约分

```c
int g = gcd(a, c);
printf("%d/%d", a / g, c / g);      // 分子分母同除 GCD
```

## 九、数组入门（P1046 首次使用）

### 声明与下标

```c
int apple[10];      // 能装 10 个整数
```

**⚠️ 下标从 0 开始，最大是"长度 - 1"**：`apple[0]` ~ `apple[9]`。

**越界访问 `apple[10]` 会导致 RE 或结果错误。**

### 循环读入

```c
for (int i = 0; i < 10; i++)
{
    scanf("%d", &apple[i]);      // ⚠️ 要 &
}
```

**⭐ 关键区别**：

| 写法 | 加 `&` 吗 |
|---|---|
| `scanf("%d", &a)` | ✅ 加（普通变量）|
| `scanf("%d", &apple[i])` | ✅ **加**（数组元素是普通变量）|
| `scanf("%s", s)` | ❌ **不加**（数组名本身就是地址）|

### 初始化

```c
int num[3] = {a, b, c};      // 用变量初始化
int ct[26] = {0};            // 全部清零（惯用写法）
```

**⚠️ 局部数组不初始化就是垃圾值** —— **计数数组一定要 `= {0}`。**

### 遍历 + 计数

```c
int count = 0;

for (int i = 0; i < 10; i++)
{
    if (apple[i] <= reach)
    {
        count++;
    }
}
```

**⭐ 这是"计数器"模式** —— 跟 `eaten++` 一样。

### 下标映射技巧

**把"字符"映射成"数组下标"**：

```c
s[i] - '0'      // 数字字符 → 数值下标（'6' → 6）
s[i] - 'A'      // 大写字母 → 下标（'A'→0, 'B'→1, 'C'→2）
s[i] - 'a'      // 小写字母 → 下标
```

**例（P4414）**：

```c
int num[3] = {a, b, c};              // 排好序的三个数
printf("%d", num[s[0] - 'A']);       // 根据字母直接取对应的数
```

**⭐ 这一招能替代一大堆 `if-else`。**

### 输出整串

```c
printf("%s", s);        // 把 char 数组当字符串整体输出
```

**⭐ 修改了 `s[12]` 之后直接 `printf("%s", s)`** —— `-` 之类的分隔符自动带上，不用手动拼。

### 分隔符的"空格在前"套路

**输出 `1 3 5` 而不是 `1 3 5 `（末尾多空格）**：

```c
printf("%d", num[0]);              // 第一个不带空格

for (int i = 1; i < 3; i++)
{
    printf(" %d", num[i]);         // ⭐ 空格在前
}
```

**⚠️ 用 `"%d "` 的写法会让最后一个数后面多一个空格** —— 可能 WA。

## 十、常用数学函数

```c
#include <math.h>
```

| 函数 | 作用 | 例子 |
|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(117.0)` → `10.8167` |
| `pow(x, y)` | x 的 y 次方 | `pow(v, 1.0/3.0)` 开立方 |
| `fabs(x)` | 浮点绝对值 | `fabs(-3.5)` → `3.5` |
| `ceil(x)` | 向上取整 | `ceil(2.1)` → `3.0` |
| `floor(x)` | 向下取整 | `floor(2.9)` → `2.0` |
| `round(x)` | 四舍五入 | `round(2.5)` → `3.0` |

### ⚠️ `abs` 和 `fabs` 不同

- `abs` 在 `stdlib.h`，处理 **int**
- `fabs` 在 `math.h`，处理 **double**

### ⚠️ 开立方用 `pow`

```c
pow(v, 1.0 / 3.0)    // ✅ 1.0/3.0 必须是浮点！
pow(v, 1 / 3)        // ❌ 1/3 = 0，结果变成 pow(v, 0) = 1
```

### ⚠️ 能整数就整数

**三角形判定用 `a*a + b*b == c*c`**（整数，精确），**别用 `sqrt` + 浮点比较**。

### ⚠️ 本地 gcc 编译要加 `-lm`

```bash
gcc a.c -o a -lm
```

**洛谷上不用管。**

### ⚠️ 浮点误差

```c
(int)pow(v, 1.0/3.0)           // 可能是 15.9999998 → 得到 15 ❌
(int)(pow(v, 1.0/3.0) + 1e-9)  // 加一点点容错 ✅
```

## 十一、字符串基础

```c
char s[100];              // 声明一个能装 100 个 char 的数组
scanf("%s", s);           // ⚠️ 不加 &，数组名就是地址
int n = strlen(s);        // 实际长度（需要 <string.h>）
```

### ⚠️ 容量 ≠ 长度

```c
char s[100086];    // 容量 100086
scanf("%s", s);    // 输入 "hello"
strlen(s)          // 长度 5
```

**字符串末尾有隐藏的 `'\0'`，所以 `char s[5]` 装不下 5 个字母。**

### 按位置取字符（定长输入）

**像 ISBN 这种格式固定的字符串，位置是死的**：

```c
s[0]        // 第 1 个字符
s[12]       // 第 13 个字符
```

**⚠️ 数组下标从 0 开始，所以第 n 个字符是 `s[n-1]`。**

### 逐字符处理

```c
for (int i = 0; i < n; i++)
{
    printf("%c", s[i]);
}
```

### 倒着打印

```c
for (int i = n - 1; i >= 0; i--)    // ⚠️ 是 n-1 不是 n
{
    printf("%c", s[i]);
}
```

### ⚠️ 字符数字 ↔ 数值

```c
s[i] - '0'      // 字符 → 数值（'6' → 6）
'0' + r         // 数值 → 字符（6 → '6'）
```

**⚠️ 忘了减 `'0'` 会全错**：`'6' * 2` 算的是 `54 × 2 = 108`。

### `continue` 和 `break`

```c
for (int i = 0; i < 12; i++)
{
    if (s[i] == '-')
    {
        continue;      // 跳过本轮剩下的代码，直接进入下一轮
    }
    // ... 处理字符
}
```

- **`continue`**：跳过本轮，继续下一轮
- **`break`**：直接跳出整个循环

## 十二、代码风格

### 缩进（Python 感的来源）

```c
int main()
{
    if (a > b)
    {
        printf("大");
    }
    else
    {
        printf("小");
    }

    return 0;
}
```

**规律**

- `{` 跟上一层**对齐**，或独占一行
- 每深一层**多 4 个空格**
- **用空格不用 Tab**（网页 IDE 里 Tab 会错位）

### 空行分组 ⭐

**用空行把"读入 / 计算 / 输出"分成块** —— 这才是看着舒服的关键。

```c
int main()
{
    int a, b;

    scanf("%d%d", &a, &b);

    int sum = a + b;

    printf("%d", sum);

    return 0;
}
```

### 空格规则

```c
printf("%d\n", a + b);        // ✅ 逗号后加空格，前面不加
scanf("%d%d", &a, &b);        // ✅
printf("%d\n" , a+b);         // ❌ 逗号前有空格，运算符没空格
```

**逗号/分号前面不加空格，后面加一个；运算符两边各一个空格。**

### 危险运算要放在安全分支里 ⭐

```c
if (t == 0)
{
    printf("0");
}
else
{
    int eaten = s / t;    // ✅ 确认 t != 0 才敢除
}
```

**曾经把 `s / t` 写在 `if` 前面 → `t = 0` 时直接崩。**

**⭐ 规则：可能出错的运算（除零、开负数根、越界），必须先确认条件安全再执行。**

## 十三、调试与排错

### ⭐ 打印调试法

**在代码里临时加 `printf` 看中间变量**：

```c
printf("读到了: %s\n", s);
printf("长度: %d\n", strlen(s));
printf("中间结果: %d\n", eaten);
```

**调完记得删掉。**

### ⭐ 手工验算法

**写完关键逻辑，用具体数字代进去念一遍**：

```c
apple / child      → "14 除以 4"  → 每人 3 个 ✔️
child / apple      → "4 除以 14"  → 0.28，取整 0 ❌ 变量放反了
```

**这个方法能抓出 90% 的"变量放反"错误。**

### ⭐ 换个角度想

**卡住时试试**：

- **做题目前先在纸上画个表**（条件 ↔ 输出），照着表写代码，写完再照着表核对
- **先用中文把步骤写成人话**，再翻译成代码
- **举 2~3 个具体例子手动推一遍**，规律自己会冒出来

### 自测清单（交之前扫一遍）

| 检查 | 说明 |
|---|---|
| **1. `&`** | `scanf` 里每个变量都有吗？ |
| **2. `==` vs `=`** | 条件里写的是两个等号吗？运算符打对了吗？ |
| **3. 拼写** | 变量名前后一致？（大小写！`lsat` vs `last`）|
| **4. 分号** | 每行结尾都有吗？ |
| **5. 括号** | 配对吗？数清楚了？ |
| **6. 格式符** | `%d` 配 int？`%lf`/`%f` 配对了吗？ |
| **7. 输入顺序** | 和题目的变量顺序一致吗？ |
| **8. 数据组数** | 有没有多读/少读一组？ |
| **9. 循环变量** | 初始化了吗？`for (int i = 1; ...)` 那个 `= 1` |
| **10. 擂台初始值** | 足够大/小吗？会溢出吗？ |
| **11. 尾行换行** | 多加 `\n` 了吗？ |
| **12. `return 0`** | 写了吗？ |

### 边界测试 ⭐

**别只用样例测，想想极端情况**：

- `t = 0`？（除零）
- 结果为负？（要不要归零）
- 数据超范围？（溢出）
- 并列的情况？（取靠前还是靠后）
- 空输入 / 单个元素？

## 十四、洛谷报错含义

| 缩写 | 全称 | 含义 | 常见原因 |
|---|---|---|---|
| **AC** | Accepted | 通过 | — |
| **WA** | Wrong Answer | 答案错 | 逻辑错、格式错、精度错 |
| **RE** | Runtime Error | 运行崩溃 | 漏 `&`、数组越界、**除以 0** |
| **TLE** | Time Limit Exceeded | 超时 | 算法太慢 |
| **CE** | Compile Error | 编译失败 | 语法错误 |
| **MLE** | Memory Limit Exceeded | 内存超限 | 数组开太大 |

### ⭐ 关键认知

> **OJ 报的是"最终状态"，不是"bug 清单"。**
> **一个 WA 背后可能藏着好几个错误，改完一个还有下一个。**

**所以修 bug 是循环**：改 → 交 → 看结果 → 改 → 交。

**⚠️ 而且"能跑"≠"对"**：

- **语法全对、类型全对、逻辑大体对** → 编译通过，大部分情况结果正确
- **所以它交出的是"看起来合理但错的答案"** —— **这是最难查的一类 bug**

### 看报错信息

**CE 时编译器会告诉你**：

```
error: 'child' undeclared; did you mean 'child3'?
```

**直接就是答案。** 越是新手越该认真读报错。

**警告也要看**：

```
warning: unused variable 'child3'
```

**"定义了但没用"** —— 常常正好指出你写错了变量名。

### 最有效的定位手段

**下载/查看测试数据，对比"我的输出 vs 标准输出"** —— 逐字符看，差在哪立刻就知道，比猜准一百倍。

## 十五、常用套路总结

### 套路 1：统一单位

**时间/钱/长度加减，先统一到最小单位，算完再换回来。**

```c
int start = a * 60 + b;      // 小时分 → 分钟
int total = end - start;
printf("%d %d", total / 60, total % 60);
```

**好处**：避免"借位"的麻烦。

### 套路 2：打擂台（找最大/最小）⭐

**这是最常用的框架之一。**

```c
int best = 初始值;              // 找最大设很小，找最小设很大
int best_day = 0;               // 顺便记住相关信息

for (...)
{
    if (当前值 比 best 更优)
    {
        best = 当前值;
        best_day = i;
    }
}
```

**⚠️ 两个坑**：

- **`>` 还是 `>=`** —— 决定"并列时保留靠前还是靠后"（题目常要求"并列取靠前的"→ 用 `>`）
- **初始值** —— 找最小要设"足够大"的数，但**不能大到溢出**

### 套路 3：枚举 + 打擂台（多方案取最优）

**"几种方案各算一遍，取最便宜/最快"**：

```c
int min_cost = 100000000;

for (int i = 0; i < 3; i++)
{
    scanf("%d%d", &per, &price);
    int packs = (n + per - 1) / per;    // 向上取整
    int cost = packs * price;

    if (cost < min_cost)
        min_cost = cost;
}
```

**注意**：**不是"单价最低就最省"** —— 要按**实际方案**算总价。

### 套路 4：先排序再判断

**排完序后，很多条件能大幅简化。**

```c
// 排序（保证 a <= b <= c）
if (a > b) { 交换 }
if (b > c) { 交换 }
if (a > b) { 交换 }     // ⚠️ 第三次不能省
```

**排序带来的简化**：

- **三角形判定**：只需检查 `a + b > c`（不用判断 3 组）
- **角度判定**：直接比较 `a² + b²` 和 `c²`（不用找最长边）
- **等腰判定**：只需 `a == b || b == c`（不用写 `a == c`）

**⚠️ 三次比较的顺序是 `ab → bc → ab`，第三次不能省**（否则中间被打乱的最小值回不到最前）。

### 套路 5：桶计数（数组当下标）

```c
int ct[26] = {0};                // 计数数组，一定初始化
for (int i = 0; i < n; i++)
    ct[s[i] - 'a']++;            // 字符 → 下标
```

**把 26 个 `if` 变成一行。**

### 套路 6：字符 ↔ 数字

```c
s[i] - 'a'      // 字符 → 下标
'a' + c         // 下标 → 字符
s[i] - '0'      // 字符数字 → 数值
'0' + r         // 数值 → 字符数字
c - 32          // 小写 → 大写（只对纯小写安全）
toupper(c)      // 更安全的转换（需要 <ctype.h>）
```

### 套路 7：倒推

**"经过一系列操作到达某个状态，问初始状态" → 从已知终点倒着推。**

**逆向运算**：加变减、减变加、乘变除、除变乘，**顺序也要倒过来**。

**例子（猴子吃桃）**：正向是 `÷2 - 1`，逆向就是 `+1 ×2`。

### 套路 8：把数学式翻译成 C

**老老实实按运算符优先级加括号**：

```c
// √(p(p-a)(p-b)(p-c))
double s = sqrt(p * (p - a) * (p - b) * (p - c));

// BMI = m / h²
double bmi = m / (h * h);
```

**⚠️ 根号/分母罩住的范围，括号必须全部包住。**

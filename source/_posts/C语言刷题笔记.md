## 一、C 程序的基本骨架

```c
#include <stdio.h>

int main()
{
    // 你的代码

    return 0;
}
```

**要点**

- `#include <stdio.h>` 用 `scanf` / `printf` 必须有
- `main` 是程序入口
- `return 0;` 表示程序正常结束（不写也能过，但养成习惯）

---

## 二、输入输出 scanf / printf

### 核心规则

> **`scanf` 要地址（`&`），`printf` 要值（不用 `&`）。**

```c
int x;
scanf("%d", &x);      // ✅ 要 &
printf("%d", x);      // ✅ 不要 &
```

**为什么？**

- `scanf` 要**往变量里写数据**，必须知道变量在哪 → 给**地址**（`&x`）
- `printf` 只是**读变量的值** → 给**值**（`x`）

**漏掉 `&` 的后果：程序崩溃 → RE**（踩过两次）

### 数组是例外

```c
char s[100];
scanf("%s", s);       // ⚠️ 数组名本身就是地址，不要加 &
```

## 三、数据类型与格式符对照表

### ⭐ 必背表

| 类型 | `scanf` | `printf` |
|---|---|---|
| `int` | `%d` | `%d` |
| `long long` | `%lld` | `%lld` |
| `float` | `%f` | `%f` |
| **`double`** | **`%lf`** | **`%f`** |
| `char` | `%c` | `%c` |
| 字符串 | `%s` | `%s` |

### ⚠️ 最容易错的点

> **`double` 在 `scanf` 里用 `%lf`，在 `printf` 里用 `%f`！**

**原因**：`printf` 会把 `float` 自动提升为 `double`，所以不用区分；`scanf` 拿到的是指针，必须区分。

### 输出控制格式

| 写法 | 效果 | 例子（值 3.14159） |
|---|---|---|
| `%d` | 整数 | — |
| `%f` | 默认 6 位**小数** | `3.141590` |
| `%.3f` | 3 位小数 | `3.142` |
| `%.1f` | 1 位小数 | `3.1` |
| `%g` | 6 位**有效数字** | `3.14159` |
| `%.6g` | 6 位有效数字 | `3.14159` |
| `%02d` | 宽度 2，不足补 0 | `08` |
| `%*c` | 宽度用变量控制 | — |

### ⚠️ 小数位数 vs 有效数字

```
%f  → 数的是"小数点后几位"    166.666667
%g  → 数的是"从第一个非零数字起一共几位"   166.667
```

### ⚠️ `%.1f` 和 `%.lf`

**`1` 是数字一，`l` 是小写字母 L** —— 长得太像，极易看错。

### ⚠️ 尾行换行

**题目输出最后一行通常不加 `\n`**，多一个都可能 WA。（B2005 就栽在这）

## 四、变量与命名规范

### 命名原则

```c
int total_jiao = a * 10 + b;   // ✅ 有意义
int x;                          // ⚠️ 太短
int ttl_Jiao;                   // ⚠️ 风格混搭
```

**C 风格**：全小写 + 下划线（`total_jiao`）或驼峰（`totalJiao`），**选一种别混**。

### ⚠️ 不要用这些名字

`cout`、`cin`、`endl`、`string`、`max`、`min`、`count`、`time`、`index`、`y1`

（都是 C++ 或标准库的名字，以后会冲突）

### 变量作用域

```c
if (t == 1)
{
    int apple = 10;    // 只在这个 {} 里活着
}
else if (t == 2)
{
    int apple = 20;    // 另一个 apple，不冲突
}
```

**`{}` 形成作用域，出了 `{}` 变量就消失了。**

## 五、运算陷阱

### ⭐ 陷阱 1：整数除法（踩过 5 次以上！）

```c
500 / 3        // = 166   整数除法，小数全丢
500.0 / 3      // = 166.6667  ✅

4 / 3          // = 1     ❌ 灾难
4.0 / 3.0      // = 1.333 ✅
```

**规则**：**只要算式里有小数，参与运算的数就必须至少有一个是浮点类型。**

**三种修法**

```c
double a = (double)t / n;     // 强制类型转换
double a = t * 1.0 / n;       // 乘 1.0
double a = 4.0 / 3.0 * pi;    // 直接写浮点
```

### ⭐ 陷阱 2：向上取整 / 向下取整

| 场景 | 方向 | 写法 |
|---|---|---|
| 至少需要几个（不够也进位） | **向上** | `(a + b - 1) / b` |
| 最多能买几个（不够就舍） | **向下** | `a / b` |

**例**：走路 10 米，速度 3 米/分 → `(10 + 3 - 1) / 3 = 4` 分钟

### ⭐ 陷阱 3：浮点数不要用 `==` 比较

```c
if (a == 0.1 + 0.2)     // ❌ 浮点几乎不可能精确相等
if (a > 0.2999)         // ✅ 用 > 或 <
```

### ⭐ 陷阱 4：`==` 和 `=` 写错

```c
if (t == 4)     // ✅ 比较
if (t = 4)      // ❌ 赋值！条件永真，t 被覆盖
```

**编译器可能只给警告，不报错。** 防御写法：`if (4 == t)`（写错会立刻报错）

### ⭐ 陷阱 5：数据范围

| 范围提示 | 用什么 |
|---|---|
| 保证答案在 int 范围内 | `int` |
| 答案可能到 10^18 | `long long` |
| 没说 | 自己估算会不会溢出 |

**`int` 上限约 21 亿（2.1 × 10⁹）**

### 陷阱 6：类型不匹配导致输出乱码

```c
printf("%d", a * 0.2 + b * 0.3);   // ❌ 算出来是 double，用 %d 打印 = 乱码
```

**`printf` 完全信任格式符**，类型错了它不知道，会读出垃圾。

## 六、逻辑运算符

| 运算符 | 读作 | 含义 |
|---|---|---|
| `&&` | 与 AND | 两边都真才真 |
| `\|\|` | 或 OR | 有一个真就真 |
| `!` | 非 NOT | 取反 |

### ⚠️ 别写成单个 `&` 或 `|`

**单个是位运算**，不是逻辑运算，**写错了不报错但结果全错**。

### 短路求值

```c
if (i < n && a[i] > 0)    // 左边假 → 右边不看 → 防越界
```

### 关系表达式本身是 1 或 0

```c
int p1 = (x % 2 == 0);       // p1 是 1 或 0
int p2 = (x > 4 && x <= 12);
int both = p1 && p2;         // 可以直接当数用
```

### "刚好一个成立" = 异或

```c
int b = (p1 != p2);    // ✅ 一真一假
```

### 优先级

```
!  >  比较  >  &&  >  ||
```

**不确定就加括号。**

## 七、常见数学函数

```c
#include <math.h>
```

| 函数 | 作用 | 例子 |
|---|---|---|
| `sqrt(x)` | 平方根 | `sqrt(117.0)` → `10.8167` |
| `pow(x, y)` | x 的 y 次方 | `pow(v, 1.0/3.0)` 开立方 |
| `fabs(x)` | 浮点绝对值 | `fabs(-3.5)` → `3.5` |
| `ceil(x)` | 向上取整 | `ceil(2.1)` → `3.0` |
| `floor(x)` | 向下取整 | `floor(2.9)` → `2.0` |
| `round(x)` | 四舍五入 | `round(2.5)` → `3.0` |

### ⚠️ `abs` 和 `fabs` 不同

- `abs` 在 `stdlib.h`，处理 **int**
- `fabs` 在 `math.h`，处理 **double**

### ⚠️ 开立方用 `pow`

```c
pow(v, 1.0 / 3.0)    // ✅ 1.0/3.0 必须是浮点！
pow(v, 1 / 3)        // ❌ 1/3 = 0，结果变成 pow(v, 0) = 1
```

### ⚠️ 本地 gcc 编译要加 `-lm`

```bash
gcc a.c -o a -lm
```

**洛谷上不用管。**

### ⚠️ 浮点误差

```c
(int)pow(v, 1.0/3.0)         // 可能是 15.9999998 → 得到 15 ❌
(int)(pow(v, 1.0/3.0) + 1e-9) // 加一点点容错 ✅
```

## 八、字符串基础

```c
char s[100];              // 声明一个能装 100 个 char 的数组
scanf("%s", s);           // ⚠️ 不加 &，数组名就是地址
int n = strlen(s);        // 实际长度（需要 <string.h>）
```

### ⚠️ 容量 ≠ 长度

```c
char s[100086];    // 容量 100086
scanf("%s", s);    // 输入 "hello"
strlen(s)          // 长度 5
```

**字符串末尾有隐藏的 `'\0'`，所以 `char s[5]` 装不下 5 个字母。**

### 逐字符处理

```c
for (int i = 0; i < n; i++)
{
    printf("%c", s[i]);
}
```

### 倒着打印

```c
for (int i = n - 1; i >= 0; i--)    // ⚠️ 是 n-1 不是 n
{
    printf("%c", s[i]);
}
```

## 九、代码风格

### 缩进（Python 感的来源）

```c
int main()
{
    if (a > b)
    {
        printf("大");
    }
    else
    {
        printf("小");
    }

    return 0;
}
```

**规律**

- `{` 跟上一层**对齐**，或独占一行
- 每深一层**多 4 个空格**
- **用空格不用 Tab**（网页 IDE 里 Tab 会错位）

### 空行分组 ⭐

**用空行把"读入 / 计算 / 输出"分成块** —— 这才是看着舒服的关键。

```c
int main()
{
    int a, b;

    scanf("%d%d", &a, &b);

    int sum = a + b;

    printf("%d", sum);

    return 0;
}
```

### 空格规则

```c
printf("%d\n", a + b);        // ✅ 逗号后加空格，前面不加
scanf("%d%d", &a, &b);        // ✅
printf("%d\n" , a+b);         // ❌ 逗号前有空格，运算符没空格
```

**逗号/分号前面不加空格，后面加一个；运算符两边各一个空格。**

### 危险运算要放在安全分支里 ⭐

```c
if (t == 0)
{
    printf("0");
}
else
{
    int eaten = s / t;    // ✅ 确认 t != 0 才敢除
}
```

**你曾经把 `s / t` 写在 `if` 前面 → `t = 0` 时直接崩。**

## 十、调试与排错

### ⭐ 打印调试法

**在代码里临时加 `printf` 看中间变量**：

```c
printf("读到了: %s\n", s);
printf("长度: %d\n", strlen(s));
printf("中间结果: %d\n", eaten);
```

**调完记得删掉。**

### ⭐ 手工验算法

**写完关键逻辑，用具体数字代进去念一遍**：

```c
apple / child      → "14 除以 4"  → 每人 3 个 ✔️
child / apple      → "4 除以 14"  → 0.28，取整 0 ❌ 变量放反了
```

**这个方法能抓出 90% 的"变量放反"错误。**

### 自测清单（交之前扫一遍）

| 检查 | 说明 |
|---|---|
| **1. `&`** | `scanf` 里每个变量都有吗？ |
| **2. `==` vs `=`** | 条件里写的是两个等号吗？ |
| **3. 拼写** | 变量名前后一致？（大小写！`lsat` vs `last`）|
| **4. 分号** | 每行结尾都有吗？ |
| **5. 括号** | 配对吗？数清楚了？ |
| **6. 格式符** | `%d` 配 int？`%lf`/`%f` 配对了吗？ |
| **7. 输入顺序** | 和题目的变量顺序一致吗？ |
| **8. 尾行换行** | 多加 `\n` 了吗？ |
| **9. `return 0`** | 写了吗？ |

### 边界测试 ⭐

**别只用样例测，想想极端情况**：

- `t = 0`？（除零）
- 结果为负？（要不要归零）
- 数据超范围？（溢出）
- 空输入 / 单个元素？

## 十一、洛谷报错含义

| 缩写 | 全称 | 含义 | 常见原因 |
|---|---|---|---|
| **AC** | Accepted | 通过 | — |
| **WA** | Wrong Answer | 答案错 | 逻辑错、格式错、精度错 |
| **RE** | Runtime Error | 运行崩溃 | 漏 `&`、数组越界、**除以 0** |
| **TLE** | Time Limit Exceeded | 超时 | 算法太慢 |
| **CE** | Compile Error | 编译失败 | 语法错误 |
| **MLE** | Memory Limit Exceeded | 内存超限 | 数组开太大 |

### ⭐ 关键认知

> **OJ 报的是"最终状态"，不是"bug 清单"。**
> **一个 WA 背后可能藏着好几个错误，改完一个还有下一个。**

**所以修 bug 是循环**：改 → 交 → 看结果 → 改 → 交。

### 看报错信息

**CE 时编译器会告诉你**：

```
error: 'child' undeclared; did you mean 'child3'?
```

**直接就是答案。** 越是新手越该认真读报错。

**警告也要看**：

```
warning: unused variable 'child3'
```

**"定义了但没用"** —— 常常正好指出你写错了变量名。

## 十四、常用套路总结

### 套路 1：统一单位

**时间/钱/长度加减，先统一到最小单位，算完再换回来。**

```c
int start = a * 60 + b;      // 小时分 → 分钟
int total = end - start;
printf("%d %d", total / 60, total % 60);
```

**好处**：避免"借位"的麻烦。

### 套路 2：桶计数（数组当下标）

```c
int ct[26] = {0};                // 计数数组，一定初始化
for (int i = 0; i < n; i++)
    ct[s[i] - 'a']++;            // 字符 → 下标
```

**把 26 个 `if` 变成一行。**

### 套路 3：字符 ↔ 数字

```c
s[i] - 'a'      // 字符 → 下标
'a' + c         // 下标 → 字符
c - 32          // 小写 → 大写（只对纯小写安全）
toupper(c)      // 更安全的转换（需要 <ctype.h>）
```

### 套路 4：倒推

**"经过一系列操作到达某个状态，问初始状态" → 从已知终点倒着推。**

**逆向运算**：加变减、减变加、乘变除、除变乘，**顺序也要倒过来**。

**例子（猴子吃桃）**：正向是 `÷2 - 1`，逆向就是 `+1 ×2`。

### 套路 5：把数学式翻译成 C

**老老实实按运算符优先级加括号**：

```c
// √(p(p-a)(p-b)(p-c))
double s = sqrt(p * (p - a) * (p - b) * (p - c));
```

**⚠️ 根号罩住的范围，括号必须全部包住。**

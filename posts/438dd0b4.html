一、C 程序的基本骨架

要点

  • #include <stdio.h> 用 scanf / printf 必须有
  • main 是程序入口
  • return 0; 表示程序正常结束（不写也能过，但养成习惯）

二、输入输出 scanf / printf

核心规则

scanf 要地址（&），printf 要值（不用 &）。

为什么？

  • scanf 要往变量里写数据，必须知道变量在哪 → 给地址（&x）
  • printf 只是读变量的值 → 给值（x）

漏掉 & 的后果：程序崩溃 → RE（踩过三次）

数组是例外

多组数据的读法

⚠️ 数清楚题目给了几组数据 —— 多读一次会吃掉后面的数据，全盘错位。

三、数据类型与格式符对照表

⭐ 必背表

⚠️ 最容易错的点

double 在 scanf 里用 %lf，在 printf 里用 %f！

原因：printf 会把 float 自动提升为 double，所以不用区分；scanf 拿到的是指针，必须区分。

⚠️ 小数位数 vs 有效数字

题目说"保留 6 位有效数字" → 用 %g；说"保留 6 位小数" → 用 %.6f。

⚠️ cout 和 printf 的默认精度不同

题目里说"用 cout 输出"时，cout 输出 double 默认是 6 位有效数字（相当于 %g），不是 printf("%f") 的 6 位小数。

⚠️ %.1f 和 %.lf

1 是数字一，l 是小写字母 L —— 长得太像，极易看错。

⚠️ 尾行换行

题目输出最后一行通常不加 \n，多一个都可能 WA。（B2005 就栽在这）

但题目明说"用换行符隔开"时，就要加。

五、运算陷阱

⭐ 陷阱 1：整数除法（踩过 5 次以上！）

规则：只要算式里有小数，参与运算的数就必须至少有一个是浮点类型。

三种修法

⭐ 陷阱 2：运算符优先级与结合性

* / % 同级，从左往右算；想改变顺序只能加括号。

⭐ 陷阱 3：向上取整 / 向下取整

场景方向写法
至少需要几个（不够也进位）向上(a + b - 1) / b
最多能买几个（不够就舍）向下a / b

例 1：走路 10 米，速度 3 米/分 → (10 + 3 - 1) / 3 = 4 分钟

例 2：需要 57 支铅笔，每包 30 支 → (57 + 29) / 30 = 2 包

原理：+ b - 1 是先垫高一点，让除不尽的情况也能进位，除得尽时又不会多加。

⭐ 陷阱 4：浮点数不要用 == 比较

能转成整数比较就转 —— 比如三角形判定用 a*a + b*b == c*c，全程整数，绝对精确。

⭐ 陷阱 5：== 和 = 写错（踩过两次）

编译器可能只给警告，不报错。 防御写法：if (4 == t)（写错会立刻报错）

⭐ 陷阱 6：整数溢出

类型范围
int±21 亿（-2147483648 ~ 2147483647）
long long±9.2 × 10¹⁸

⭐ 判断方法：数位数。10 位以内 int 安全，11 位以上要 long long。

⚠️ 溢出后果：不报错、不崩溃，就是结果莫名其妙（常常变成负数）。

⭐ 擂台初始值要"够大"，但不是"越大越好" —— 要按题目范围估算上界。

阶梯计价（分段累加）

现实里的电价、水费、个税都是这种算法 —— 不是整段按一个价，而是每档各算各的。

⚠️ 最容易错的两点：

  • 后面的分支忘了把前面的档"算满"
  • 把"档位宽度"和"n - 上限"搞混（第二档宽度是 400 - 150 = 250，不是 n - 150）

⭐ 套路：每一档都要"前档算满 + 本档算超出部分"。

八、函数（P1888 首次使用）

定义与调用是两回事

⭐ 类比：定义 = 造机器，调用 = 按按钮用机器。

⚠️ 函数不能定义在函数里面

函数是"平级"的 —— gcd 要写在 main 的上方。

参数是"值传递"（复制）

函数里的 a、b 是新的变量，值是外面传进来的副本。

⚠️ 在函数里改 a、b，不影响 main 里的变量。

这就是为什么排序那段必须写在 main 里 —— 它要真正修改 main 的变量。

辗转相除法求最大公约数（GCD）

原理：反复用"除数变被除数，余数变除数"，直到余数为 0，此时的被除数就是 GCD。

例：gcd(12, 8) → (8, 4) → (4, 0) → 返回 4 ✔️

十二、代码风格

缩进（Python 感的来源）

规律

  • { 跟上一层对齐，或独占一行
  • 每深一层多 4 个空格
  • 用空格不用 Tab（网页 IDE 里 Tab 会错位）

空行分组 ⭐

用空行把"读入 / 计算 / 输出"分成块 —— 这才是看着舒服的关键。

空格规则

逗号/分号前面不加空格，后面加一个；运算符两边各一个空格。

危险运算要放在安全分支里 ⭐

曾经把 s / t 写在 if 前面 → t = 0 时直接崩。

⭐ 规则：可能出错的运算（除零、开负数根、越界），必须先确认条件安全再执行。

⭐ 关键认知

OJ 报的是"最终状态"，不是"bug 清单"。
一个 WA 背后可能藏着好几个错误，改完一个还有下一个。

所以修 bug 是循环：改 → 交 → 看结果 → 改 → 交。

⚠️ 而且"能跑"≠"对"：

  • 语法全对、类型全对、逻辑大体对 → 编译通过，大部分情况结果正确
  • 所以它交出的是"看起来合理但错的答案" —— 这是最难查的一类 bug

下载/查看测试数据，对比"我的输出 vs 标准输出" —— 逐字符看，差在哪立刻就知道，比猜准一百倍。

十五、常用套路总结

套路 1：统一单位

时间/钱/长度加减，先统一到最小单位，算完再换回来。

好处：避免"借位"的麻烦。

套路 2：打擂台（找最大/最小）⭐

这是最常用的框架之一。

⚠️ 两个坑：

  • > 还是 >= —— 决定"并列时保留靠前还是靠后"（题目常要求"并列取靠前的"→ 用 >）
  • 初始值 —— 找最小要设"足够大"的数，但不能大到溢出

套路 3：枚举 + 打擂台（多方案取最优）

“几种方案各算一遍，取最便宜/最快”：

注意：不是"单价最低就最省" —— 要按实际方案算总价。

套路 4：先排序再判断

排完序后，很多条件能大幅简化。

排序带来的简化：

  • 三角形判定：只需检查 a + b > c（不用判断 3 组）
  • 角度判定：直接比较 a² + b² 和 c²（不用找最长边）
  • 等腰判定：只需 a == b || b == c（不用写 a == c）

⚠️ 三次比较的顺序是 ab → bc → ab，第三次不能省（否则中间被打乱的最小值回不到最前）。

逆向运算：加变减、减变加、乘变除、除变乘，顺序也要倒过来。

十七、踩过的坑速查

按踩坑顺序排列，每一个都是真实犯过的错。

#题目错误教训
1B2005输出多了尾行换行尾行 \n 会导致 WA
2P5703scanf("%d%d", x, y) 漏 &漏 & → RE
3P5705循环写成 i = 3，漏了最大下标下标是 0 到 len-1
4P5708s / S 大小写不一致C 大小写敏感
5P5708%.lf（字母 l）当成 %.1f（数字 1）这俩长得太像
6P1421int price = 19 漏分号交前扫一眼分号
7P3954%d 打印 double 表达式类型必须匹配格式符
8B2029scanf 又漏 &第二次踩同一个坑
9P2433if (t = 4) 少一个等号赋值 vs 比较
10P2433child 写成 child3 的错拼看编译器警告
11P24334 / 3 整数除法球体积少 1.33 倍
12P2433cout 输出精度 ≠ printf("%f")cout 相当于 %g
13P2433child / apple 变量放反用"念一遍"法自查
14P5709scanf 顺序写成 m s t（题目是 m t s）顺序必须对齐题面
15P5709s / t 写在 if (t == 0) 之前危险运算要放安全分支里
16P5709变量名打错 lsat警告"未使用变量"是线索
17P5709忘了"正在吃的苹果"也要减读题注意定语"完整的"
18P5711if(a || b) || c) 括号位置错if 的外层括号要包住整个条件
19P5714m / h * h 把 h 约掉了优先级！要写 m / (h*h)
20P5714else () 多了括号else 后面不能有括号
21P5716if (month = 1, 3, 5, 7)C 没有"是其中之一"的语法
22P5716把 8 月当成 30 天一三五七八十腊，三十一天永不差
23P1085抄了"升级版"的题解抄之前先看输入格式
24P1085for (int i; i <= 7, i++) 用逗号for 三段用 ; 分隔
25P1085int i; 没初始化垃圾值 → 循环次数随机
26P1085开头多读了一次 scanf数清楚题目给几组数据
27P1085maxtime > 0 应为 > 8判断条件要对上题意
28P1909min_cost = 10086 太小擂台初始值要按范围估算
29P1909(n = per - 1) 把 + 打成 =手滑的 = 会污染数据
30P1909int 装 12 位数溢出11 位以上要 long long
31P5717把"等腰"塞进角度的 else不同维度不能用同一条链
32P5717条件和输出对不上号先画"条件 ↔ 输出"对照表
33P1422阶梯电价只按单一单价算分段计价要"前档算满"
34P1422int price = power * 0.4463浮点结果要存 double
35P1422151 < power < 400C 不支持链式比较
36P1422if (power < 150) 漏了边界 150看清"及以下"包含端点
37P1422全角括号 printf（...）输入法切到英文再写代码
38P1888三个交换写成了 else if 链都要执行的步骤用独立 if
39P1888函数定义写在 main 里C 不允许嵌套定义函数
40P1888gcd 里 return 0 应为 return a循环结束时 a 才是答案
41P1888定义了函数却没调用要有 int g = gcd(a, c);
42P4414scanf 三个变量又漏 &第四次踩同一个坑
43P4414定义了 num 数组却没用写了不用的代码要删
44P4414用 "%d " 输出导致末尾多空格分隔符用"空格在前"
45P1055数组开 char s[10086]按需分配，13 个字符开 20 就够

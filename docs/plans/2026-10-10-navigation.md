# 导航工具区与磨砂底色优化

## 批准范围

用户批准保留原搜索、美化、昼夜卡通图标及顺序，优化点击区与间距，将粉蓝渐变改为浅色暖白、深色灰黑半透明磨砂；首页大图首屏保持透明。

配置没有对应布局/底色细项，因此通过配置注入独立 source/css/navigation.css，不修改 themes/、导航模板、事件或脚本。已有未提交修改全部保留；不提交、推送或部署。

## 修改与兼容

- _config.fomalhaut.yml：在既有 site-inject.css 后添加同步导航样式链接，版本 20261010-nav1，原运行时空槽与其他资源顺序不变。
- source/css/navigation.css：桌面 44×44px 触控区、8px 间距、24px 两侧留白；<=800px 改 4px 间距、12px 留白；<=480px 站名20px，允许窄屏截断但不压缩触控区。原 SVG 尺寸与引用不变，仅消除 inline top 偏移。
- 不给 #menus 增加定位，保留中部菜单/标题的绝对居中、方向切换与800px移动折叠；769–800px同步隐藏标题以防遮挡工具区。
- 延用主题滚动 class 与常驻显示变量，不改导航 position/top/transform/display。原主题滚动阈值约56px，非新增逐像素滚动逻辑。
- 底色使用RGBA，不降低整体透明度；无磨砂支持时仍有高不透明度底色，支持时启用12px模糊。主题色仅用于交互提示，补充焦点样式与减少动态效果适配。
- 阅读模式窄域隐藏导航，防止原常驻!important规则盖过主题阅读模式隐藏。

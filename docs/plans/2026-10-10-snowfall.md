# 自然落雪与薄积雪

用户确认改善圆点式雪花并增加页面底部堆积。保持默认关闭、仅桌面浅色及萤火虫互斥，不提交/推送/部署，不改主题源码。

## 实现
- 新雪花模块 snow.js 取代 effects.js 旧圆点循环；缓存简单六臂及分枝六臂两张雪片图，大小/透明度/速度分层，轻微旋转、横向摇摆。无鼠标排斥的乱飞。
- 时间步进而非帧数，dt上限50ms，暂停恢复不补跑；epoch保护取消的旧回调，避免重复RAF。
- 真正落到底部才增加宽度有界的高度图，平滑雪面、冷白渐变，最高厚度随视口14–30px，不能越积越高挡阅读。指viewport底部，随滚动固定，不对正文布局做真实堆物。
- default off无粒子/缓存分配，关闭清雪与积雪；切深色、后台、手机或减少动态时暂停不增高；开启其他效果关雪同样清空。恢复默认关雪/清堆积。
- 缓存依DPR重用，DPR<=2；resize/PJAX重新绑定、单loop/监听，缺画布/RAF安全。
- snow/effects/settings/CSS版本snow1，fireflies保持fireflies1，其余模块不动。
